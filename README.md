Entry for make.fun's "Sum up 18 November's world news in one image" bounty: a newspaper-style infographic of Wednesday 18 November 2026. Six stories: the APEC summit opening in Shenzhen with a first Xi-Trump-Putin meeting set for Thursday, the US strike on an Iranian missile base on Qeshm Island and attacks traded across the Gulf, North Korea's ballistic missile launch towards the Sea of Japan, Russia-Ukraine drone strikes despite Abu Dhabi peace talks, a 5.3 magnitude earthquake in Romania, and NASA's Voyager 1 about to reach one light-day from Earth.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies the finished 1024x1024 PNG (`entry.png`) to the output directory as `entry.png`. The image was rendered at build time from `render.html` with headless Chromium (`render.py`); `main.py` itself is stdlib-only and needs no network.
